## 是什么

一个桌面端的动效工程工具，官网标题是「帧驭 MotionHarness — 万千动态 由你导演」。它的工作方式不是「生成一段视频就结束」，而是：

1. 你用自然语言把需求交给编程 Agent（Claude Code / Codex 这类），Agent 创建一个 MotionHarness 动画工程。
2. 打开 Studio，选图层、调开放出来的参数、拖关键帧、调运动曲线。
3. 在画面上加「AI 标记」，把要改的地方指给 Agent 看；Agent 读取标记后改工程。
4. 导出视频或可编辑工程；装了可选桥接组件后，可以把动效作为素材送进达芬奇，并在达芬奇里回头打开原工程继续改。

官网 meta description 写得很直：让 Agent 创建动画，在 Studio 中调参数、关键帧和曲线，添加 AI 标记，导出视频或可编辑工程，并接入达芬奇剪辑。站点资源里还能读到 MCP、Agent Hook、Standard / Pro 两档工程、macOS 与 DaVinci Resolve Studio 的桥接限制。

## 关键技法

1. **交回「可编辑的中间物」，不是成片。** 传统 AI 视频的终点是 mp4；这里的终点是一个工程：图层、参数、关键帧、曲线都在。成片可以重开、可以改一处而不重做全片。
2. **参数化边界。** Agent 只开放一部分参数给 Studio（位置、大小、颜色、字号等），运动命门留在工程里。这和 video-talkcraft 的「改皮不改命门」是同一个思路。
3. **Standard / Pro 分层。** Standard 面向模板内容编辑，Pro 才有完整关键帧时间线。降低第一次上手的复杂度，不牺牲深度。
4. **标记即接口。** 在画面上圈一个位置、写一句修改要求，Agent 读取标记和附件再改。比在聊天里描述「左上角那个字」精确。
5. **动效进剪辑软件，而不是导出后失联。** 桥接后素材与工程保持关联，更新工程会更新时间线上同一素材的所有引用，保留剪辑位置和裁切。
6. **参数实时可调。** 调速度、字重、字距、冲量、强调色，画面立刻变；这是「导演」感成立的前提。

## 如何复用到我们的管线

- 做展示页：把「参数实时可调」做成真的控件，而不是一张参数截图。本页的 Canvas 动力学字效有速度、字重、字距、冲量、强调色五个控件，Standard / Pro 切换会显示或隐藏关键帧轨。
- 做交付：任何动效都留一份可改的源（HTML/CSS/JS 或工程文件），不要只交 mp4。
- 做协作：修改意见尽量带时间码和画面位置，像 AI 标记那样；不要写「再高级一点」。
- 做工程管理：一页一套内联 CSS/JS，共用一份 GSAP，不装每页 node_modules。
