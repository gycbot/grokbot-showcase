从画廊借来的

三条纪律，
让参考墙不变成垃圾场。

Framer Gallery 的结构很克制：分类、缩略图、一个 Open。学到的是取舍，不是把页面塞满。

01

分类只做两级

一级行业，二级场景。两级还找不到，说明这张卡不该收。

02

图先说话

卡片上只留名称、维度和一个动作。判断发生在图里，不在介绍文案里。

03

一个动作

打开，或者收进记忆。不同时给收藏、点赞、分享、下载四个按钮。

记忆怎么用

三步，把「看过」变成「用得上」。

记忆不是聊天记录。它只保留你反复确认过的偏好，并且允许你改。

01 / COLLECT

收窄

一次只收一个维度。八张卡里三种版式，比八十张截图更好用。

02 / DISTILL

归纳

把重复出现的词提出来，写成一句能执行的话：暖纸、大字、单栏、少动效。

03 / APPLY

起稿

下次先按这句偏好出一版，再让你改。改完的结论回写记忆。

许可与边界

借结构，不借作品。

画廊里的每一张图都归作者；这面墙的八张卡全部是本页用 CSS 画的抽象版式。

使用边界

只链原站，不搬图。Framer Gallery 的作品归各自作者 / 客户，Framer 的名称与界面归 Framer；本页没有下载或再分发任何截图、视频。

「Framer Gallery」只作被介绍对象的名称，不使用其 logo 或品牌色作为本页品牌。

若要批量抓取画廊做训练或再发布，需要先看 Framer 服务条款与各作品授权；本任务不做。
