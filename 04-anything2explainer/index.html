CH 01 / 写入

只留三类。

不是把整段对话存下来。只留会被下一次任务用到的三类：偏好、纠正、项目事实。其余的，让它们留在那一次对话里。

  • 事实本批只做第 1–4 项；交付写到共享目录；索引只改自己那几行。

写的时候带来源：哪次任务、哪句纠正、什么时候。

CH 02 / 取用

下次先读，再动手。

同类任务开始时，先取出相关记忆：哪些偏好要遵守，哪些纠正不能再犯，哪些事实已经核实。读完，再排步骤。

这一步不花多少时间，但能省掉一轮「不是这样的」。

读的是相关记忆，不是全部历史。相关性由任务类型决定。

CH 03 / 纠正

被纠正一次，
就改一次。

主人说「不要紫色主色」，这句话不该只生效一次。它要写回记忆，下一次同类任务先读到。

纠正不是道歉，是改文件。旧的那条划掉，新的那条写上，标清楚是哪一次改的。

版本号不是装饰：v1 错在哪、v2 改了什么，要能对上。

CH 04 / 遗忘

看得到，
也删得掉。

记忆不是黑箱。哪些写了、什么时候写的、来自哪次纠正，都能翻出来；不想要的，可以删。

删除不是把抽屉锁上，是把那张卡拿走。空出来的位置，下一次可以写新的。

可读、可改、可删，三件事缺一不可。

边界 / 记忆不做什么

记得住，
也要守得住。

01 / FACT

只记事实与偏好

不把猜测写成记忆，不把一次性的情绪当成长期偏好。写进去的，要能指回来源。

02 / NO CLAIM

不宣称意识

记忆是文件，不是体验。它让下一次少说一遍，不代表它「记得你」这件事有主观感受。

03 / CONTROL

主人随时可删

看得到、改得动、删得掉。删除之后，下一次任务不再引用那条。
