为什么是工程

成片是终点，
工程是下一次的起点。

一段渲染好的视频，改一个字要重做全片；一份工程，改一个图层只重跑一个镜头。这也是委派这件事真正省时间的地方。

01

图层还在

标题、主角、背景、证据各自独立。要换哪一层，改哪一层。

02

参数有名

位置、大小、颜色、字距是具名参数，不是散落在代码里的魔法数字。

03

曲线可读

关键帧和时间线留在工程里，能看出动作在哪一秒加速、哪一秒停。

04

回链成立

送进剪辑软件的素材和工程保持关联，更新工程会更新同一素材的引用。

两档工程

先用 Standard 把内容改对，
再进 Pro 调动效。

产品把编辑界面分成两档。上方控制条里的 STANDARD / PRO 可以切换，Pro 会多出一条关键帧轨。

STANDARD 模板级

  • 改文案、颜色、图片、基础位置
  • 开放常用参数，不暴露时间线
  • 适合把模板快速改成自己的内容

PRO 完整工程

  • 关键帧、运动曲线、图层顺序
  • Standard 的改动会保留，Pro 里继续加动画
  • 适合要交给剪辑、还要反复改的片子
交接链路

四棒，每一棒都留下可改的东西。

Grok Bot 负责前两棒：理解需求、把工程写出来；Studio 和剪辑软件负责后两棒，把判断留在人手里。

01 / ASK

说需求

一句话描述画面、时长、气质。Agent 先读技能，再动手。

02 / BUILD

写工程

Agent 生成工程文件并打开 Studio。图层和参数已经就位。

03 / TUNE

调关键帧

在 Pro 时间线里拖点、改曲线。改完加标记，让 Agent 接着改。

04 / SHIP

导出或回剪

导出视频 / 工程，或经桥接送进达芬奇，素材与工程保持关联。

AI 标记

用手指，而不是用形容词。

在画面上圈一个位置，写一句具体的要求；Agent 读取标记和附件再改。比在聊天里说「左上角那个字再大一点」少来回几轮。

站点文案原话：在 Studio 添加标记，再请 Agent 读取。
