# 如何替换照片和文字

这是「把伞偏向你」沉浸滚屏相册。不需要服务器、不需要安装任何东西：用浏览器直接打开 `index.html` 就能完整看完（`file://` 也可以）。

建议用 Chrome、Edge 或 Safari 打开。第一次打开时如果浏览器问「是否允许本地文件访问」，选允许即可；本页不会联网，也不会收集任何东西。

---

## 一、先看文件结构

```
index.html                 页面本身，不用改
config.js                  名字、日期、短句、情书、照片说明——只改这里
photos/01.jpg … 08.jpg     照片，文件名与 config.js 里一一对应
assets/                    字体、动效、GSAP；日常换图换字不用动
如何替换照片和文字.md        本说明
```

---

## 二、改文字（3 分钟）

用记事本、VS Code、TextEdit（纯文本模式）打开 `config.js`。

```js
window.KEEPSAKE = {
  title: "把伞偏向你",
  personA: { name: "周予安", short: "予安" },
  personB: { name: "梁清和", short: "清和" },
  metOn: "2018-06-17",
  anniversary: "2026-06-17",
  metPlace: "夜雨里的末班车候车亭",
  hook: "把伞偏向你那一侧，已经八年。",
  hookSub: "不是誓言。是每次下雨都会做的事。",
  letter: "清和：\n写这页的时候……",
  signature: "予安",
  letterDate: "2026-06-17",
  closing: "这一页没有结尾。\n下次下雨，再往你那边偏一点。",
  chapters: [ … ]
};
```

逐项说明：

| 字段 | 改成什么 |
| --- | --- |
| `title` | 浏览器标签上的名字，也是整页的标题 |
| `personA` / `personB` | 两个人的名字。`name` 是页面上的大字，`short` 是顶栏和信里用的短称呼 |
| `metOn` | 相识日，格式必须是 `YYYY-MM-DD` |
| `anniversary` | 纪念日，格式同上；只用来算年份范围 |
| `metPlace` | 相识地点，一句话 |
| `hook` | 开场那一句。建议 12–22 个字，太长会换行 |
| `hookSub` | 开场下面的一行小字，可以留空 |
| `letter` | 情书。用 `\n` 换行；第一行可以写「清和：」 |
| `signature` | 落款。最后一个字会被做成红色印章 |
| `letterDate` | 落款日期 |
| `closing` | 收尾的一句。用 `\n` 可以指定换行 |
| `chapters` | 每一张照片的说明，见下 |

### 加减照片章节

`chapters` 是一个列表，想加就复制一段、想减就删掉一段：

```js
{
  photo: "photos/03.jpg",
  date: "2019-01-26",
  place: "厨房",
  caption: "一盏灯，两双筷子。面煮好了才发现没买葱。",
  note: "冬至后第三十天"
}
```

- `date` 可以留空（`""`），页面会写「未署期」。
- `place` 会出现在照片下方的章节号和目录里。
- `note` 是照片左下角那行小字，可以留空。
- 页面的红线、目录、进度都会按章节数量自动重算，不用改动画代码。

改完保存，回到浏览器按 `Ctrl/Cmd + R` 刷新。

> 注意：不要删掉第一行的 `window.KEEPSAKE = {`，也不要删掉最后的 `};`。字符串里的引号要用英文引号 `"`，中文引号会报错。

## 三、换照片（5 分钟）

把你的照片放进 `photos/`，**用同名文件覆盖**：`01.jpg`、`02.jpg`…… 与 `chapters` 里写的文件名一致即可。

建议：

- 比例 **4:5 竖图** 最稳（例如 1152 × 1440）。横图也能用，画面会从中间裁切；重要的人脸/物件尽量放在中间。
- JPEG，单张 200–500 KB 比较合适；整包不要超过 20 MB。
- 文件名只用英文、数字、下划线；不要用空格或中文文件名（个别手机会打不开）。
- 换之前先备份原图，想改回时方便。

如果想让某张照片用别的文件名，同时改 `config.js` 里的 `photo` 字段即可，例如 `photo: "photos/us-01.jpg"`。

---

## 四、刷新与检查

1. 保存 `config.js` 和照片。
2. 回到浏览器刷新。
3. 名字、日期、开场句、照片、目录应该一起变。
4. 点右上角「目录」可以跳章节；页面底部有「打印这一页」，会生成一份适合打印的版本。

## 五、常见问题

**打开是空白 / 只有文字没有动效？**
先确认 `config.js` 没有语法错误（少一个逗号、引号不配对都会让整页停住）。用 Chrome 打开后按 F12 → Console，红色报错会指出第几行。

**照片换了但页面还是旧的？**
确认文件名大小写完全一致（`03.jpg` 不是 `03.JPG`），然后强制刷新：`Ctrl/Cmd + Shift + R`。

**一定要联网吗？**
不用。字体、GSAP、照片全部在本地。整个文件夹拷到 U 盘、发微信压缩包都能打开。

**可以放到自己的网站吗？**
可以。把整个文件夹上传到任意静态空间，`index.html`、`config.js`、`photos/`、`assets/` 保持同样的相对位置即可。

**可以商用吗？**
这套模板里的字体是 SIL OFL 1.1，GSAP 核心与 ScrollTrigger 使用 GSAP Standard License，照片是随包附带的原创插画（仅作样张，正式使用请换成你们自己的照片）。具体许可见 `assets/LICENSES/` 与包内 `LICENSE_NOTES.md`。不要转卖模板本身，成品页面可以自用或送给对方。

**想改颜色？**
打开 `assets/css/style.css`，最上面 `:root` 里的 `--paper`、`--ink`、`--rose` 三个值改掉即可；改颜色不需要懂动画。

**手机上文字太大/太小？**
不要改字号，先在手机上横屏看看；这版是按 390 × 844 调过的。确实要改，调 `style.css` 里 `@media (max-width: 819px)` 中的 `.name` 与 `.ch-caption` 字号。
