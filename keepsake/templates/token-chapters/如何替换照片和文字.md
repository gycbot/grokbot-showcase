# 如何替换照片和文字

这是「盒里的一句」三维信物页。不需要服务器：用 Chrome / Edge / Safari 直接打开 `index.html`，`file://` 也能完整使用。三维部分用 WebGL；极老的设备没有 WebGL 时，会自动换成静态说明，文字仍然可读。

名字、年份、盒盖刻字、里层短句、四段文字和收尾照片，全都在 `config.js` 里。换这些不需要改三维代码。

---

## 一、文件结构

```
index.html                 页面本身，不用改
config.js                  所有可换的文字和照片，只改这里
photos/01.jpg …            照片，默认用 01.jpg
assets/                    字体、three.js、GSAP、场景代码
如何替换照片和文字.md        本说明
```

---

## 二、改文字

用纯文本编辑器打开 `config.js`。

```js
window.KEEPSAKE = {
  title: "盒里的一句",
  eyebrow: "A KEEPSAKE IN FOUR CHAPTERS",
  personA: { name: "周予安", short: "予安" },
  personB: { name: "梁清和", short: "清和" },
  metOn: "2018-06-17",
  anniversary: "2026-06-17",

  engraving: {
    names: "周予安 · 梁清和",
    years: "2018 — 2026"
  },

  inside: "把伞偏向你那一侧。",
  insideSmall: "已经八年。",

  heroLine: "有些话不写在纸上。",

  chapters: [ … ],

  closing: "下次下雨，再往你那边偏一点。",
  photo: "photos/01.jpg",
  photoCaption: "2018.06.17 · 候车亭",
  photoAlt: "雨夜的候车亭与一把红伞"
};
```

| 字段 | 说明 |
| --- | --- |
| `title` | 首屏大标题与浏览器标签 |
| `engraving.names` | 盒盖第一行刻字，建议 8–12 个字以内 |
| `engraving.years` | 盒盖第二行，通常是年份范围 |
| `inside` | 打开盒子后看到的那一句，建议 8–14 个字 |
| `insideSmall` | 盒子里的小字，一行 |
| `heroLine` | 首屏标题下的一句 |
| `chapters` | 四段正文（固定四段，顺序对应 01–04） |
| `closing` | 最后一屏的收尾句 |
| `photo` | 收尾章节的小照片（桌面显示，手机为保持信物构图不显示） |
| `photoCaption` / `photoAlt` | 照片说明与无障碍描述 |

四段正文每一项：

```js
{
  no: "01",
  label: "盒盖",
  title: "两个名字，一场雨",
  body: "盒盖上刻着两个名字……"
}
```

- 建议标题 6–12 个字，正文 35–60 个字。
- 四段的 `no` / `label` 也会出现在底部章节导航里；改 `label` 时保持 2–3 个字最稳。
- 顺序不要调换，场景的四个动作（合着 → 打开 → 里层 → 合上）是按顺序编排的。

保存后刷新。盒盖与里层的刻字是运行时用字体画进纹理的，改完名字刷新就会重新生成，不需要重新导出。

> 中文名字建议不超过 12 个字；太长会缩小或超出盒盖边缘。

## 三、换照片

1. 把照片放进 `photos/`。
2. 在 `config.js` 里把 `photo` 改成对应文件名，例如 `photo: "photos/us.jpg"`。
3. 刷新。

建议 4:5 竖图（如 1152 × 1440），JPEG，200–500 KB。页面里这张照片只作为收尾的记忆卡，不会进入三维纹理，所以不会因为 file:// 的跨域限制出问题。

> 手机端为了不让照片盖住信物，收尾照片不显示；桌面端显示。需要手机也显示，可以在 `assets/css/style.css` 的 `@media (max-width: 900px)` 里把 `.memento { display: none; }` 改成 `display: block;`，再适当缩小标题字号。

---

## 四、滚动与交互

- 往下滚：盒盖合着 → 镜头靠近刻字 → 盒盖打开 → 看到里层一句 → 合上。
- 每章的背景色用 `color-mix(in oklch, …)` 过渡（深釉 → 夜蓝 → 暖赭）。
- 桌面端移动鼠标时，信物会有很轻的视差；手机不启用。
- 底部 `01–04` 可以点，直接跳到对应章节；右上角有当前进度。
- 如果浏览器不支持 WebGL，页面顶部会出现一行说明，三维层关闭，四段文字与照片仍可读。

## 五、常见问题

**打开是黑屏，只有底部导航？**
先看 `config.js` 是否有语法错误。F12 → Console 的红色报错会指向行号。若提示 WebGL 不可用，是浏览器/显卡禁用，页面会自动降级，不该黑屏。

**刻字没变？**
强制刷新 `Ctrl/Cmd + Shift + R`。刻字在页面加载时生成，改完必须刷新。

**名字太长，盒盖上放不下？**
把 `engraving.names` 缩到 10 个字以内，或把 `personA.name` 改成短称呼。

**需要联网吗？**
不需要。three.js、GSAP、字体、照片都在本地。整个文件夹拷走即可。

**能改盒子形状/材质吗？**
可以，但需要改 `assets/js/scene.js`。几何是代码里用椭圆挤出、铰链、内衬和刻字平面搭的，没有外部模型；改 `ovalShape` 的半径、`silver` 的 color/roughness 就能变。日常换名字换日期不需要动这里。
