# 如何替换照片和文字

这是「八年的站与站」关系图谱。不需要服务器：用 Chrome / Edge / Safari 直接打开 `index.html` 即可，`file://` 也能完整使用。

图谱、站序、右侧站点卡片共享同一份 `config.js`。改文字、换照片都不用碰绘图和动效代码。

---

## 一、文件结构

```
index.html                 页面本身，不用改
config.js                  所有可换的文字和照片，只改这里
photos/01.jpg … 08.jpg     照片，文件名与 chapters 一一对应
assets/                    字体、Canvas 图谱脚本、GSAP
如何替换照片和文字.md        本说明
```

---

## 二、改文字

用纯文本编辑器打开 `config.js`。

```js
window.KEEPSAKE = {
  title: "八年的站与站",
  kicker: "2018 — 2026 · 8 站",
  intro: "把日子按站名排一遍。点一个站，看看那天。",
  quote: "把伞偏向你那一侧，已经八年。",
  personA: { name: "周予安", short: "予安" },
  personB: { name: "梁清和", short: "清和" },
  metOn: "2018-06-17",
  anniversary: "2026-06-17",
  chapters: [ … ]
};
```

| 字段 | 说明 |
| --- | --- |
| `title` | 页面主标题与浏览器标签 |
| `intro` | 标题下的一句话 |
| `quote` | 站点卡片最下面那句 |
| `personA` / `personB` | 两个人的名字 |
| `metOn` / `anniversary` | 相识 / 纪念日，格式 `YYYY-MM-DD` |
| `chapters` | 站点列表，也是图谱的节点数据 |

每个站点：

```js
{
  photo: "photos/03.jpg",
  date: "2019-01-26",
  place: "厨房",
  tag: "家",
  caption: "一盏灯，两双筷子。面煮好了才发现没买葱。",
  note: "冬至后第三十天"
}
```

- `place` 是站名，会画在图谱节点上，也会出现在底部站序里，建议 2–4 个字。
- `date` 决定节点下方的年份；留空会显示「未署期」。
- `tag` 是图谱上的**支线**：同 tag 的站会被一条虚线连起来（样张里是「雨」和「家」）。不需要支线就把 `tag` 删掉或都填不一样的。
- `caption` 显示在右侧/下方的站点卡片里，建议 25–45 个字。
- `note` 是照片下方那行小字，可以留空。

站的数量可以增减：图谱会按数量自动排布节点，站序、左右切换、自动导览都会跟着变。建议 5–10 站；超过 12 站手机上图例会变密。

改完保存，刷新页面即可。

## 三、换照片

把照片放进 `photos/`，覆盖同名文件：`01.jpg`、`02.jpg`……

- 比例 **4:5 竖图**（如 1152 × 1440）最稳；右侧卡片按 4:5 裁切，手机上是 16:10 横幅，会从中间裁。
- JPEG，单张 200–500 KB。
- 文件名用英文/数字，和 `config.js` 里的 `photo` 完全一致（大小写敏感）。
- 站点卡片会预载所有照片，整包建议不超过 20 MB。

## 四、怎么玩这张图

- **拖动**：按住画布拖，游走整张图。
- **缩放**：桌面滚轮；手机双指捏合。
- **点站**：点节点，右侧（手机是下方）换成那一站的照片与说明。
- **站序**：底部一排按钮，点任意一站直接跳过去；手机上这排会吸顶。
- **全图**：把视角拉回能看见所有节点。
- **走一遍**：自动按顺序走完八站，再按一次停。
- **键盘**：← → 换站，Esc 停止自动导览。

换文字不会影响这些操作；图谱的坐标和连线都由数据算出来。

## 五、常见问题

**打开只有文字，没有图？**
确认 `config.js` 语法正确（引号、逗号成对）。F12 → Console 会指出错误行号。

**图谱是空白的？**
本页用 Canvas 2D 绘制，不依赖 WebGL；如果仍然空白，检查是否用很旧的浏览器（IE 不支持）。Chrome、Edge、Safari、Firefox 近三年的版本都可以。

**节点挤在一起？**
站太多或站名太长。把 `place` 缩到 2–4 个字，或把站点减到 10 个以内。

**照片换了不生效？**
文件名大小写、扩展名要一致；强制刷新 `Ctrl/Cmd + Shift + R`。

**需要联网吗？**
不需要。字体、GSAP、照片都在本地，整个文件夹可以直接发压缩包。
